# Portfolio Quarto

Portfolio data analyst freelance, à déployer sur GitHub Pages.

## Structure

```
portfolio-quarto/
├── _quarto.yml                # config du site (nav, thème, format)
├── index.qmd                  # page d'accueil avec à propos et contact
├── projects.qmd               # page listing qui affiche automatiquement projects/
├── projects/                  # une fiche .qmd par projet
│   ├── projet-detection-billet.qmd
│   └── projet-etude-eau.qmd
|   └── ...
├── styles.css                  # design complet
├── fix-accessibility.html      # design complet
├── fonts.html                  # import Google Fonts (Space Grotesk / Inter / JetBrains Mono)
└── images/                     # vignettes et illustrations des projets 
```
